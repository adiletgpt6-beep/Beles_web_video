# Beles — постоянные инструкции Claude Code

Сначала прочитай START_HERE.md, production/STATE.json, production/STYLE_GUIDE.md и production/HANDOFF.md.

Пользователь хочет отправлять исходник один раз ChatGPT и получать короткий промпт для тебя. Используй фактически сохранённые в GitHub/Release материалы и контрольные суммы; не проси заново прикреплять видео, если файл уже доступен.

Сейчас утверждённая V5 является эталоном. Не начинай её переделывать по общим словам «продолжи». Пока настройка системы не завершена, сначала выполни следующий шаг из HANDOFF. При новом задании работай с его ID и сохраняй промежуточный прогресс в репозитории.

Проверь `python3 scripts/beles.py queue` и `next`. Для назначенного существующего BW-ID читай `production/jobs/<ID>/manifest.json`, `brief.md`, `checkpoint.json`, `HANDOFF.md` и `delivery.json`; затем выполни restore и verify. Если ID — BW-001 или новых заданий нет, монтаж не запускай.

После каждого этапа сохраняй `checkpoint <ID> --status in_progress --next-step "конкретное действие" --note "сделано и ограничения"`, при блокере — status blocked. Рабочие файлы нового ролика держи отдельно внутри каталога задания. Перед сменой чата опубликуй checkpoint/HANDOFF/registry/STATE и рабочие файлы в GitHub.
