# Beles: начать здесь

Это постоянная точка входа в проект. Источник истины — этот репозиторий; содержание прошлых чатов не заменяет актуальные файлы.

1. Прочитайте `production/STATE.json` — утверждённый эталон и состояние настройки.
2. Прочитайте `production/STYLE_GUIDE.md` — обязательные правила следующих роликов.
3. Прочитайте `production/HANDOFF.md` — что уже сделано и следующий конкретный шаг.
4. Для передачи новых файлов используйте `production/INGEST.md`; готовые короткие сообщения — `production/PROMPTS.md`.

Рабочая и сейчас основная ветка: `ccr-443bddaf-7eho4h`. Ветки `main` при проверке не было. Перед записью проверяйте текущую основную ветку через GitHub и не затирайте параллельные изменения.
