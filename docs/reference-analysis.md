# Разбор референса (38 с, 720×1280, другой ведущий)

Референс использовался только как образец приёмов; его кадры, ведущий и звук в итог не входят.

| Приём референса | Как это устроено | Как перенесено в монтаж |
|---|---|---|
| Ведущий — основа кадра | Ведущий в центре/низу кадра всё время, графика над головой | Камера всегда на ведущем; для карточек кадр масштабируется ×1.25 от верхнего края, голова опускается до y≈750 и освобождает верх |
| Двухуровневый заголовок | Маленькая акцентная строка (оранжевый курсив) + крупная белая узкая строка капсом | Montserrat Italic 700 золотисто‑оранжевый `#FFC25C` + Oswald 700 белый капс, тень для читаемости на красной шторе |
| Карточки сайта | Широкая карточка под заголовком, белый фон, скругления, тень; меняются страницы | Карточка 900×384 в рамке браузера (точки + адрес), скругление 26 px, двойная тень; 3 реальных вида zeket.kg |
| Движение | Карточка появляется сверху, внутри сменяются экраны; лёгкие приближения | Пружинное появление 0.4 с, плавный «скролл» и приближение внутри карточки, курсор и подсветка нужного блока |
| Смена планов | Чередование среднего и чуть более крупного плана на склейках | wide / medium (×1.14) / close (×1.26) / card (×1.25) — смена крупности на каждой склейке маскирует jump‑cut |
| Субтитры | Короткие группы 2–4 слова, внизу, белые | 2–5 слов, Montserrat 800, ключевое слово золотым, тёмная полупрозрачная подложка (белая рубашка!) |
| Финал | Крупный призыв «Пиши: …» в верхней зоне | «Бизге азыр жазыңыз: WHATSAPP» — точно по финальной фразе ведущего, без выдуманных контактов |
| Отдельный план | Коллаж фото поверх ведущего | Полноэкранный план «телефон» с реальной мобильной версией сайта и размытым ведущим на фоне (голос не прерывается) |
