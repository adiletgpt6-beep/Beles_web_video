# V4: субтитры без подложки и новая подача

Файл: `release/beles-web-v4-1080x1920.mp4` — 1080×1920, CFR 30 fps, H.264 yuv420p, AAC 48 kHz, faststart.
Предыдущие версии сохранены: `release/beles-web-v3-1080x1920.mp4`, `release/beles-web-v2-1080x1920.mp4`, `release/v1-beles-web-final-1080x1920.mp4`; данные V3 — `data/v3/`.

**Важно про референс.** Файла нового референса `1000218363.mp4` среди загруженных в сессию не было: доступны только задание V4, исходник и старый референс. V4 собрана по подробному описанию приёмов из задания. Покадровое сравнение с самим роликом‑референсом не выполнялось.

## 1. Подложка субтитров удалена

- Старый компонент `src/Subtitles.tsx` (плашка `rgba(22,9,7,0.72)`, тень, варианты A–E) удалён целиком. Композиция `SubStyle` и скрипт сравнения стилей удалены.
- Нижняя часть общей виньетки (затемнение низа кадра) удалена. Осталась только верхняя, для карточек сайта.
- Новый слой `src/Captions.tsx`: у текста и всех его контейнеров нет `background`, `boxShadow`, `backdropFilter`, `filter` и `textShadow`. Есть только тонкий тёмный контур букв (`-webkit-text-stroke` с `paint-order: stroke fill`, видимая толщина ≈3 px), чтобы белые буквы читались на белой рубашке.
- Рендер идёт из исходного видео, старые субтитры нигде не вшиты.

## 2. Динамика текста

- Смысловые группы по 2–4 слова, с пословной синхронизацией из V3 (`edit.json → segments[].words`).
- Строки:
  - слова до ключевого — небольшая белая строка, Montserrat 800, 62 px;
  - ключевое слово (или подряд идущие ключевые) — отдельная крупная строка Montserrat 900 до 124 px, голубой `#38CCFF`, размер подбирается под ширину;
  - слова после ключевого — небольшая строка ниже.
- Каждое слово входит в момент, когда звучит. У ключевого слова буквы появляются по очереди (шаг 0.9 кадра, подъём и масштаб 0.7→1 за 6 кадров), дальше стоят резко и неподвижно.
- Законченная фраза уходит одним движением: подъём на 22 px и исчезновение за 5 кадров.
- Расположение:
  - **chest** — у груди и рук, низ блока y = 1560;
  - **low** — ниже телефона на плане сайта;
  - **top** — над головой в финале, где внизу контактный блок.
  
  Справа запас 180 px, снизу ≥ 320 px.

## 3. Подача монтажа

Структура: обращение в камеру → предложение и сайт → полноэкранная типографическая сцена → снова ведущий → финальный призыв.

- Верхние заголовки над карточками и подпись «Телефон · компьютер» убраны: они повторяли субтитры. Акцентный цвет графики переведён на голубой (подсветка блока, метка «МИСАЛ»).
- **Новая полноэкранная сцена** (`src/TypeScene.tsx`, ≈19.9–22.5 с) на фразе «Бизнесиңизди жаңы деңгээлге көтөрүүгө»:
  - тёмный фон, тонкая медленно плывущая сетка, мягкое голубое свечение;
  - сначала «Бизнесиңизди», затем по буквам крупные голубые «ЖАҢЫ» и «ДЕҢГЭЭЛГЕ»;
  - на «көтөрүүгө» рисуется растущая линия;
  - сцена открывается снизу вверх, продолжая уход окна сайта вверх. Уходит шторкой вверх и открывает крупный план на «убакыт келди».
  - Сцена заодно закрывает момент, когда в единственном дубле этой фразы опущен взгляд. Голос идёт без разрыва.
- Сайт: раскрытие карточки в большой показ с кликом и подсветкой, match cut телефон → компьютер — из V3, телефон чуть уменьшен, чтобы под ним поместились субтитры.
- Дубли и их взгляд в камеру — без изменений с V2. Синхрон губ сохранён: видео и звук режутся по одним кадрам.

## 4. Звук и финал

- Новые акценты: whoosh на открытии типографической сцены, pop на появлении «ЖАҢЫ», swish на уходе сцены. Остальные — как в V3.
- Музыка тихая, разрешается на появлении номера.
- WhatsApp‑блок с номером **0998 08 38 28** — ниже руки по направлению жеста, двухэтапное появление (24.07 / 24.23 с), до конца ролика. Субтитры финала над головой.
