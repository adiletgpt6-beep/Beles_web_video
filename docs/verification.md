# Проверка итогового MP4

Файл: `release/beles-web-final-1080x1920.mp4` (14.0 МБ). Сырые данные проверки: `docs/verification-raw.txt` (`scripts/verify.sh`).

## Параметры (ffprobe)

| Параметр | Требование | Факт |
|---|---|---|
| Разрешение | 1080×1920, 9:16 | 1080×1920 |
| Частота | CFR 30 fps | r_frame_rate = avg_frame_rate = 30/1, 794 кадра = 26.467 с |
| Видео | H.264, yuv420p | H.264 High, yuv420p, bt709, ~4.0 Мбит/с (CRF 16) |
| Звук | AAC 48 kHz | AAC‑LC, 48 kHz, стерео (моно‑голос), 256 кбит/с |
| faststart | да | `ftyp, moov, free, mdat` — moov в начале |
| Декодирование | полностью | `ffmpeg -v error -f null` — 0 ошибок |
| Громкость | −14…−16 LUFS | −15.1 LUFS integrated, LRA 2.5 LU |
| True peak | ≤ −1 dBTP | −1.6 dBTP в мастер‑WAV, −4.6 dBFS после AAC |
| Чёрные кадры | нет | blackdetect — нет |
| Тишина > 0.5 с (−40 dB) | только осмысленная | одна: 25.67–26.47 — финальная улыбка после последнего слова |

Превью `preview-720x1280.mp4`: 720×1280, 30 fps, H.264 CRF 21 + AAC 160 кбит/с, 4.2 МБ.

## Содержательная проверка

- **Просмотр**: весь ролик просмотрен покадрово (каждый 6‑й кадр, 133 контрольных кадра) + полноразмерные стоп‑кадры ключевых моментов. Начало сразу с фразы‑крючка, финал на улыбке, без технических реплик и уходов из кадра.
- **Звук vs субтитры**: финальная дорожка повторно распознана кыргызской моделью по каждому из 7 фрагментов; текст совпадает с субтитрами. Отличия только орфографические, описаны в `docs/transcript.md` (жокбу→жокпу, брондор→брондоо, тотал→татаал).
- **Склейки**: все 6 стыков находятся в паузах; максимальный скачок сэмпла на стыке ±10 мс — 0.000 (щелчков нет). Видео и звук режутся по одним и тем же кадрам исходника (`data/edl.csv`), поэтому синхрон губ сохранён.
- **Буквы ө ү ң**: отображаются в заголовках (Oswald) и субтитрах (Montserrat), шрифты загружаются локально, рендер ждёт `document.fonts`.
- **Безопасные зоны**: субтитры заканчиваются на y=1596 (нижние 300 px свободны), слева от 90 px, справа не ближе 180 px; заголовки начинаются с y=168. Карточки сайта 900×384 (≈20% высоты, вместе с заголовком ≈28%) — над головой, лицо не перекрывают (в режиме карточки голова опущена до y≈750).
- **Сайт**: только реальные скриншоты zeket.kg/ky от 27.10.2026; демонстрационный телефон, цифры статистики и тестовые проекты не показаны.
- **Исходный звук**: в оригинале пиковые значения достигают 0 dBFS — в выбранных дублях 3–17 клиппированных сэмплов на фразу (на взрывных согласных). Понижение уровня их не восстанавливает; на слух это короткие единичные пики, искажений голоса анализ не выявил.

Ограничение проверки: собственно «прослушивания» ушами у меня нет — звук проверен измерениями (LUFS/true peak, стыки, тишина) и повторным распознаванием речи.
