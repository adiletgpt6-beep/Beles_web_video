# Обязательная выдача готового видео — все задания BalaGo Studio

Правило применяется к **каждому** видео, полученному через BalaGo Studio, независимо от выбранного репозитория, исходного формата MOV/MP4 и версии монтажного стиля.

## После завершения монтажа Claude Code ОБЯЗАН
1. Экспортировать финальный видеофайл **.mp4** (H.264 + AAC, yuv420p, faststart), не просто переименовывать MOV.
2. Проверить файл: ffprobe, воспроизведение, наличие аудио/видео, синхронизацию, отсутствие повреждений, размер и длительность; зафиксировать SHA-256.
3. Загрузить проверенный MP4 в одобренное постоянное хранилище, предпочтительно Cloudflare R2 через существующий авторизованный механизм Studio. Не хранить большие MP4 в GitHub. Исходник не удалять.
4. Предоставить пользователю **две разные ссылки**:
   - **Смотреть** — открывается в браузере и позволяет немедленно просмотреть видео (Content-Type: video/mp4, поддержка HTTP Range).
   - **Скачать MP4** — по нажатию сразу начинается скачивание (Content-Disposition: attachment; filename="JOB-ID.mp4"). Не ссылку на страницу просмотра, GitHub Issue или приватный R2-объект.
5. Если прямые ссылки требуют авторизации, реализовать безопасные HTTPS endpoints в Studio: публичный доступ только к конкретному разрешённому готовому результату, непредсказуемый идентификатор или короткоживущий подписанный URL, без раскрытия R2 ключей, секретов и сырого исходника. Срок действия и способ обновления ссылок должны быть понятны пользователю. Не делать весь бакет публичным.
6. Проверить обе ссылки HTTP-запросом и, по возможности, воспроизведением/скачиванием; скачать и сверить размер и SHA-256. Если ссылка не проверена — **не утверждать**, что она работает.
7. В финальном ответе Claude Code указать: ID задания, статус QA, **«▶ Смотреть видео»**, **«⬇ Скачать MP4»**, длительность и размер. Сохранить обе ссылки (или стабильный безопасный способ получения ссылок) в STATUS/HANDOFF и карточке Issue.
8. **Нельзя отмечать работу «готово»**, пока MP4 не проверен и обе ссылки не работают. При блокировке записать точную причину и следующий шаг, не выдавать вымышленные URL.

Это правило является требованием к процессу. Для реальной автоматической выдачи Studio может понадобиться отдельная реализация backend для просмотра и скачивания; одна инструкция в GitHub не создаёт эти endpoints.
