# Передача исходников: требуемый процесс

Этот документ задаёт порядок; реализация загрузки/очереди пока не завершена. Смотрите STATE.json и HANDOFF.md.

1. Пользователь один раз прикладывает новый исходник к ChatGPT. Агент читает START_HERE и проверяет актуальную очередь, прежде чем назначать новый BW-ID.
2. Определить роль вложений: исходник, готовый результат или новый референс. Не принимать утверждённый ролик за сырой исходник.
3. Снять размер, SHA-256 и ffprobe. Сохранить неизменённый оригинал в GitHub: небольшой файл — обычный Git blob; крупный — предпочтительно GitHub Release. Контрольные суммы и постоянный путь/URL записать в manifest задания.
4. Использовать доступные GitHub-инструменты. `create_file/update_file` предназначены для UTF-8; бинарный MP4 нельзя передавать им как текст. Git Data `create_blob` поддерживает `encoding: base64`, затем blob подключается к дереву, коммиту и ветке. Большие данные не печатать в чат.
5. Учитывать предел обычного Git: 100 MiB на файл, предупреждение после 50 MiB. Не обещать бесконечную загрузку без проверки действующих ограничений и доступного инструмента. Для Release предпочтительна загрузка бинарного ассета с исходной контрольной суммой. Платный LFS/облачные ресурсы автоматически не включать.
6. Опубликовать media + manifest + brief + начальное состояние задания согласованно. Проверить новый head и доступность источника из чистого checkout/по Release; сравнить SHA-256.
7. Только после проверки выдать короткий промпт Claude: «Прочитай START_HERE.md и смонтируй BW-XXX по утверждённому стилю V5. Всё необходимое в GitHub; продолжай по HANDOFF задания».
8. Claude сохраняет расшифровку, выбор дублей, таймлайн, код, прогресс, результаты и проверку в каталоге задания; обновляет handoff перед длительными этапами и передачей контекста. Пользователь получает ссылки посмотреть/скачать и на код.

Обязательные сведения manifest: ID, роль, оригинальное имя, байты, SHA-256, durable path/URL, тема, язык, сайт при необходимости, контакт, версия стиля, текущий этап, следующий шаг, пути результатов. Чувствительный контент и изменения публичности оцениваются по фактическому материалу и разрешению пользователя.

Подписка ChatGPT/Claude не пополняет баланс стороннего OpenAI API. При отсутствии распознавания сначала использовать реально доступные средства, сохранять блокер и продолжать независимые этапы; не выдумывать речь.
