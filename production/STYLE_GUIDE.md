## Темп и монтаж

Сильная первая фраза без заставки. Смысловые блоки: обращение → предложение → наглядный пример → польза → призыв. Длительность нового ролика определяется его связной речью.

В эталоне семь речевых фрагментов: 3,21 / 1,83 / 5,11 / 7,46 / 2,98 / 2,86 / 4,72 с. Это ориентир организации речи, не инструкция резать через одинаковый интервал. Внутри фрагментов графика меняет композицию по смыслу.

Чередовать выразительный момент с короткой спокойной фазой чтения. Уместны крупный текст за ведущим, отдельная типографическая сцена, видеокарточка, круглая маска, продолжение движения карточки сайта, мобильный показ, простые иконки произносимых понятий. Применять по смыслу нового материала, сохраняя цельный стиль.

Выбирать дубли со взглядом в объектив; сохранять естественные моргания. Короткое чтение с экрана можно закрыть мотивированной вставкой, сохранив голос. Синхрон губ и речи обязателен. Крупность — с учётом детализации исходника. Не заменять лицо и не подделывать взгляд.

## Субтитры

Короткие смысловые группы на языке записи; для кыргызского проверять ө, ү, ң. Основная часть белая, главное слово крупнее и голубое. Текущий акцент: `#38CCFF`; шрифты проекта Montserrat и Oswald с кириллицей-ext.

Текст непосредственно поверх видео. Общая чёрная/полупрозрачная плашка, общий blur, широкая тень и затемнение под строкой запрещены пожеланием пользователя. Возможен тонкий контур букв для контраста.

Вход слов/букв связан с реальной речью; устойчивая фаза даёт время прочитать. Не терять части предложения при замене субтитра декоративным словом. Положение меняется по композиции, не перекрывая лицо, руку, сайт и контакт.

## WhatsApp и звук

Постоянный контакт: **0998 08 38 28**; международный формат +996 998 08 38 28.

Если в новом исходнике есть жест вниз, плашка появляется синхронно с ним ниже пальца. Крупный номер в одну строку, читаемый не менее 3 секунд и до завершения призыва. Отдельная карточка контакта допустима; это не подложка субтитров.

Сохранять живой голос. Негромкая инструментальная музыка разрешена, когда помогает подаче. Эффекты поддерживают значимые входы/окончания движения, не каждое слово. Голос остаётся главным. Ориентир микса −14…−16 LUFS integrated, true peak ≤ −1 dBTP; проверять фактический результат.

## Сайт, экспорт, проверка

zeket.kg — пример для исходного ролика о разработке сайтов. Для новых роликов сайт/тема берутся из задания. Использовать реальные страницы и сохранённые кадры; не придумывать функции, статистику и гарантии.

Учитывать интерфейс Reels: исходные ориентиры безопасных полей 90 px слева, 180 справа, 160 сверху, 300 снизу, с проверкой реальной композиции.

Экспорт: H.264, 1080×1920, CFR 30 fps, yuv420p, AAC 48 kHz, faststart. Отдельные версии, исходный код, EDL/таймлайн и субтитры сохраняются. Результат просматривается со звуком и в размере телефона; выполненные проверки и ограничения записываются честно.
