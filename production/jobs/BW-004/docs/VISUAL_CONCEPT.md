# BW-004 (Studio VID-001) — визуальная концепция «Үч ката» («Три ошибки»)

Записано до монтажа, 2026-11-07. Основание — фактическая речь исходника (docs/transcript.md): ведущий предупреждает о трёх ошибках при заказе сайта и предлагает сделать сайт, учитывающий их.

## Аудитория и задача
Владельцы малого бизнеса в Кыргызстане, которые собираются заказать сайт. Задача — польза (чек-лист из трёх ошибок) → доверие → призыв написать в WhatsApp 0998 08 38 28. Никаких цифр, гарантий и обещаний, которых нет в речи.

## Грамматика A/B (новое обязательное правило STYLE_GUIDE 2026-11-07)
- **A — ведущий + субтитры.** Только ведущий (красная студийная штора) и бело-голубые кинетические субтитры без подложки. Никаких карточек, иконок, номеров поверх.
- **B — полноэкранный «лист проверки».** Тёплая бумага `#F2EEE5` с тонкой медленно плывущей сеткой, тёмные чернила `#10233F`, красный «ошибка» `#E0473F`, зелёный «исправлено» `#16A36A`. Ведущий полностью закрыт непрозрачной бумагой; голос продолжается за кадром; на экране только короткий заголовок/ярлык сцены, поток субтитров выключен (полный текст — в отдельном SRT).
- **Переход:** ведущий мягко растворяется в **пустой** лист (10 кадров), и только на полностью непрозрачной бумаге въезжают элементы; на выходе элементы уходят первыми, затем пустой лист растворяется обратно в ведущего. Ни одного кадра «ведущий + элемент». Без вспышек, глитчей, резких зумов; звуковые акценты — только мягкие на входе сцены и на ключевых состояниях.
- Контраст «тёплая красная студия ↔ светлый лист» сам по себе делает смену режимов читаемой и спокойной.

## Сцены B
1. **«3 КАТА»** — огромная цифра 3, красное слово «КАТА», три пустые ячейки, в которых прорисовываются красные ✕ на «кетирбеңиз».
2. **1-ката: красота вместо удобства** — крупный смартфон с демо-макетом «красивой» страницы (градиент, курсив, крошечная бледная кнопка → кольцо «Баскыч кайда?»), затем шторка открывает понятный экран с большой зелёной кнопкой «Заказ берүү»; ✕ → ✓.
3. **2-ката: не проверили на телефоне** — десктопная вёрстка, втиснутая в телефон: мелкий текст, обрезано справа (ярлыки «Майда текст», «Кесилип калды»), затем перестраивается в мобильную колонку; ✕ → ✓.
4. **Чек-лист «Баарын эске алабыз»** — те же три ячейки, красные ✕ по очереди превращаются в зелёные ✓: «Ыңгайлуулук», «Телефондогу көрүнүш», «Өнүктүрүү».
5. **Финал WhatsApp** — иконка чата (своя векторная, не логотип), «WhatsApp», номер **0998 08 38 28** крупно в одну строку, зелёная кнопка «Бизге жазыңыз»; держится до конца ≥ 3 с.

Все экраны телефонов — собственные демо-макеты с подписью «ДЕМО-МАКЕТ», только кыргызские надписи; реальные сайты не показываются (в речи сайт не назван — WEBSITE_SHOWCASE_RULES п. 4).

## Типографика и движение
Montserrat 900 для заголовков и подписей, Oswald 700 для цифр (3, номер телефона). Движение — мягкое ease-out 10–16 кадров, шторки и перестройка экранов 16 кадров, без «эффекта на каждое слово».
