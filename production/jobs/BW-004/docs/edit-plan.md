# BW-004 — монтажный план (концепция «Үч ката», см. VISUAL_CONCEPT.md)

Структура по реальной речи: **вопрос-хук → «3 ката» → ошибка 1 → ошибка 2 → ошибка 3 → «всё учтём» → предложение → призыв WhatsApp**. Длительность 33,30 с (999 кадров @ 30 fps), 6 реплик + 3,3 с тихого хвоста под финальной карточкой.

Строгое чередование режимов (A — ведущий + субтитры; B — полноэкранный лист, ведущего не видно):

| Кадры | Режим | Реплика (голос) | Что на экране |
|---|---|---|---|
| 0–71 | A medium | Сайт жасатканы жатасызбы? | ведущий, субтитры «Сайт» (голубой) |
| 71–141 | B «three» | анда бул үч катаны кетирбеңиз. | «Сайт жасатканда / 3 / КАТА», три ячейки, красные ✕ на «кетирбеңиз» |
| 141–207 | A close | Биринчи ката: сайттын кооздугуна көңүл буруу, | ведущий, субтитры |
| 207–323 | B «beauty» | сайт кооз эле эмес, кардарга ыңгайлуу болушу керек. | 1-КАТА, телефон: «красивый» экран → кольцо «Баскыч кайда?» → шторка к понятному экрану, ✕ → ✓ |
| 323–408 | A medium | Экинчи ката: телефондон кандай ачыларын текшербөө, | ведущий, субтитры |
| 408–531 | B «mobile» | анткени көпчүлүк кардарлар телефон аркылуу киришет. | 2-КАТА, десктоп в телефоне («Майда текст», «Кесилип калды») → мобильная колонка, ✕ → ✓ |
| 531–629 | A close | Үчүнчү ката: сайтты жасап, анан өнүктүрбөй коюу. | ведущий, субтитры |
| 629–720 | B «checklist» | Биз бул нерселердин баарын эске алып, | «Баарын эске алабыз», три ✕ превращаются в ✓ (Ыңгайлуулук / Телефондогу көрүнүш / Өнүктүрүү) |
| 720–805 | A medium | бизнесиңизге лайыктуу заманбап сайт түзөбүз. | ведущий, субтитры |
| 805–857 | A close | Сизге сапаттуу сайт керекпи? | ведущий, субтитры (склейка A→A со сменой крупности) |
| 857–999 | B «cta» | Анда бизге жазыңыз. + тишина | WhatsApp, **0998 08 38 28** (с 870-го кадра, ≥ 4,2 с на экране), кнопка «Бизге жазыңыз» |

Точные кадры — `data/timeline.generated.json`, EDL — `data/edl.csv` / `data/edl.edl`, субтитры — `data/subtitles.srt` (полный текст, включая реплики под B-сценами; в самом видео в режиме B субтитры выключены).

**Переходы:** каждый B — 10 кадров растворения ведущего в пустой лист → элементы на непрозрачной бумаге → элементы уходят (8 кадров) → 10 кадров растворения пустого листа в ведущего. Все смены дублей, кроме offer→cta, происходят под полностью непрозрачной бумагой (проверено по таймлайну: склейки на 129, 311, 519, 640, 900-м кадрах внутри «живой» фазы B), поэтому прыжки кадра не видны.

**Склейки звука:** реплики режутся по паузам энергетической карты (`data/asr/vad-voiced-intervals.txt`) с 12-мс фейдами; голос не меняется; губы синхронны покадрово (видео и звук режутся по одним и тем же кадрам).

**Кадрирование A:** лицо cx 560, cy 720, верх волос y≈460; чередование medium (×1,14) и close (×1,26), лёгкий наезд +1,5 % внутри кадра. Субтитры — центр полосы 90–900 px, низ блока 1530 px (выше зоны интерфейса Reels).

**Звук:** голос — highpass 75 Гц, afftdn, лёгкая презенс-EQ, компрессия; музыка — собственный генератор `scripts/make-music.py` (`MUSIC_BPM=100 MUSIC_TRANSPOSE=2`), −21 дБ с дакингом, акцент-аккорд с появлением номера; 12 тихих акцентов (swish на входе B-сцены, pop на ✓, tick на пунктах чек-листа, chime на номере). Громкость −15 LUFS integrated.
